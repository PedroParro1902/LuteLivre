# 🔒 Política de Segurança — LuteLivre

## 🛡️ Versões suportadas

O projeto **LuteLivre** mantém suporte apenas para a versão mais recente.

| Versão | Suporte |
|--------|--------|
| latest | ✅ Suportada |
| anteriores | ❌ Não suportadas |

---

## 🚨 Relatar vulnerabilidades

Se você descobrir uma vulnerabilidade de segurança no projeto **LuteLivre**, por favor **não abra uma issue pública**.

Em vez disso, reporte de forma responsável através do seguinte canal:

📧 Email: pedrohcparro@gmai.com

Inclua, se possível:
- Descrição clara do problema
- Passos para reproduzir
- Impacto potencial
- Sugestões de correção (opcional)

---

## ⏱️ Tempo de resposta

Nosso objetivo é responder aos relatórios dentro dos seguintes prazos:

- 🔹 48 horas: confirmação do recebimento
- 🔹 7 dias: análise inicial do problema
- 🔹 variável: correção dependendo da gravidade

---

## 🔐 Escopo da política

Esta política cobre:

- Código-fonte do repositório **LuteLivre**
- Assets e scripts do jogo
- Dependências incluídas diretamente no projeto

Não cobre:

- Serviços de terceiros
- Bibliotecas externas não modificadas
- Infraestrutura fora deste repositório

---

## 🧪 Boas práticas de segurança

Para manter o projeto seguro, recomendamos:

- ❌ Não expor senhas, tokens ou chaves no código
- 🔐 Usar variáveis de ambiente quando necessário
- 🧹 Revisar Pull Requests com atenção
- ⚠️ Evitar dependências desconhecidas ou não confiáveis

---

## 🙏 Agradecimento

Agradecemos qualquer contribuição responsável para melhorar a segurança do **LuteLivre**.

Sua ajuda é importante para manter o projeto seguro para todos.
